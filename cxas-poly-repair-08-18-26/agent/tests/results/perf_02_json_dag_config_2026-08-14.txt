Change 2 of N: emit the DAG config as a compact JSON string parsed at call time, instead
of a pretty-printed Python literal.

VERDICT: ACCEPTED. Proven at the per-call level (the mechanism) and at the turn level
(the outcome), with behavior unchanged.

SDK change: packages/flows/src/flows/emit/scaffold.py, `_starter_dag_code`.
  pprint.pformat(cfg)  ->  _CONFIG = '<compact json>' ; return json.loads(_CONFIG)
CES recompiles a tool's module on every invocation — proven independently by the engine's
own module-level caches (`_RAW_CONFIGS`, `_COMPILED_CONFIGS`) coming back empty each call —
so a large Python literal is recompiled per call, while a single string constant is one
AST node plus a C-speed parse.

The emitter now also REFUSES a config JSON would alter (a tuple round-trips to a list
silently). One comparison per build; the failure it prevents is invisible.
